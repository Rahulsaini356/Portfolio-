# Rahul Saini • Developer Portfolio

A modern, high-performance portfolio crafted with **Next.js 16**, **React 19**, **Three.js**, **Tailwind CSS v4**, and **Framer Motion**.

Featuring an interactive 3D celestial core, space developer command dashboard, fluid kinetic layouts, and sound synthesizer feedback.

---

## 🌟 Key Features

- **Interactive 3D Celestial Core & Planet**: Built with Three.js and React Three Fiber with 360° drag-to-rotate physics and warp acceleration.
- **Developer Command Dashboard**: Live system telemetry, active project radar, and visualizer mode toggles (Orbit, Warp, Flare).
- **Modern Project Showcase**: 2x2 featured grid and editorial list views highlighting CineStream, Aura Apparel, Atmos Weather, and Cinematic Studio.
- **Clean Chronological Timeline**: Academic journey and project milestones with responsive layout choreography.
- **Audio Synthesizer Engine**: Lightweight Web Audio API micro-sound feedback with persistent global mute/enable toggle.
- **Obsidian Dark Aesthetic**: Deep cosmic space palette with hair-line glassmorphism, responsive typography, and 100/100 Lighthouse performance.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Library**: React 19
- **3D Graphics**: Three.js, React Three Fiber
- **Styling**: Tailwind CSS v4, Glassmorphism
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Audio**: Web Audio API Synthesizer

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Rahulsaini356/Portfolio-.git
cd Portfolio-
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3005](http://localhost:3005) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
